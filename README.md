# aarshpatel.github.io/website

Personal website of Aarsh Patel, served by GitHub Pages from the `master` branch.

- `index.html` — the whole site (plain HTML/CSS/JS, no build step)
- `Aarsh_Patel_Resume.pdf` — resume linked from the site
- `.nojekyll` — tells GitHub Pages to serve files as-is

To edit, change `index.html` and push. Changes are live about a minute later.
